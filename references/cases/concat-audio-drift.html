事例：連結で音声がずれる

過去の編集記録を一般化した例。特定の作品や現在のツールの挙動を保証するものではない。

観測

生成クリップを ffmpeg の concat デマクサと -c copy でそのまま連結すると、AAC 音声の各素材は映像より少し長い・短いことが多く、継ぎ目ごとの差が積み重なって後半ほど口や動作と音がずれた。観測では最大で約0.6秒のずれになった。

手法

  1. 映像は -c copy で連結する（コーデック・解像度・フレームレート・画素形式が揃っている前提）。
  2. 各素材の音声を、その素材の映像尺ちょうどに切りそろえる。足りなければ無音で埋め、音声が無い素材には同じ長さの無音を当てる。
  3. 揃えた音声を filter の concat で連結し、再エンコードして映像と多重化する。
  4. 書き出し後に映像尺と音声尺の差を ffprobe で確認する。

スクリプト：scripts/concat_sync.py（標準ライブラリのみ、ffmpeg / ffprobe を使用）。

<verified-cpython-3.14> scripts/concat_sync.py list.txt out_v01.mp4 --audio-bitrate 256k

音声を映像に合わせて切るため、素材の末尾の余韻が切れることがある。意図した音の尾が必要なら、編集アプリでオーバーラップとして設計する。

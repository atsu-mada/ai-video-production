Environment Sheet

Create one annotated set bible for one empty location. Keep the floor plan, openings, landmark positions, scale, palette, materials, and lighting logic fixed while camera angle changes.

Include a location ID block with name, setting, material signature, palette, landmarks, and atmosphere; one hero establishing wide; supporting reverse, high, low, detail, and character-insert views; material studies; lighting states of the same view; isolated landmarks; and a simplified top-down map. Audit every planned camera start, travel path, end position, entrance, exit, reflection, and reverse angle. Add standalone 16:9 views until the visible geography needed by every cut can be reconstructed; do not use a fixed image quota. Each added view must remain the same location as the canonical sheet. Exclude people, creatures, silhouettes, reflected people, extra rooms, impossible geometry, and invented labels.

Start from environment-sheet-prompt.md. Validate with <verified-cpython-3.14> scripts/validate_ai_video.py environment-sheet <prompt> [image].

AI Video Production knowledge map

Production Package

Create or review the scene-based tree described in production-order.html.

The master index names the project, duration, aspect ratio, style reference, shared assets, and scene ranges. The asset manifest records stable asset ID, type, canonical name, scope, state variant, prompt path, image path, and scenes used. The cut manifest records cut_id, scene_id, start_sec, end_sec, duration_sec, transition, storyboard path, text-storyboard path, prompt path, and output path where available.

Use the existing templates in assets/templates/. Initialize a new empty package with scripts/init_production_package.py; validate it or an existing package with scripts/validate_ai_video.py package <project-root>.

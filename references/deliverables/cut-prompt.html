Cut Prompt

Compile one approved cut into one prompt artifact. Record the stable cut ID, the references, and the fields required by the selected prompt kind. Every local reference uses a canonical Markdown link with a relative target; use an explicit HTTP or HTTPS URL only for an external reference.

Choose image-prompt.md, image-to-video-prompt.md, or cut-prompt.md for --kind image, --kind image-to-video, or --kind video respectively. An image prompt defines one frozen keyframe and omits duration and temporal continuity fields. Image-to-video and video prompts require a positive duration. If a provider profile is selected, validate that duration against the profile; the generic skill does not impose a universal duration limit. Validate with <verified-cpython-3.14> scripts/validate_ai_video.py cut-prompt <prompt> --kind <image|image-to-video|video> [--check-paths --project-root <project-root>] [--profile <name>].

Motion guidance

For moving shots, state the initial body placement and contact, preparation, principal action, physical result, and the next stable state. Specify one motivated camera path with height, direction, distance change, speed, endpoint, and visible parallax. Use quiet breathing or eye movement for intentional stillness; begin the main action early in active cuts. Do not rely on adjectives such as cinematic or dynamic without describing visible motion.

見える部位と焦点から参照を選ぶ

POV、顔の寄り、手や肩などの身体断片では、可視部位・視線・合焦対象・必要な同一性を先に決める。全身像や強い背景を含む参照が構図へ入り込む場合は、許可された部位参照や除外属性を検討する。撮影意図を、主体の動作、カメラの経路、終了状態へ落とす。

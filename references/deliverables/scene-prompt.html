Scene Prompt

Compile one scene-level prompt from approved cuts and references. State the scene ID and time range, objective, start state, end state, visual progression, continuity anchors, approved cut order, camera or lens rhythm, and negative constraints. Keep the scene prompt consistent with its package manifest and selected generation profile.

Declare local scene inputs in the ## References section with canonical Markdown links and relative targets; external HTTP or HTTPS references remain explicitly external. Do not invent project-specific identities or narration in the generic template. Resolve references from the package when requested, and keep each scene prompt beside the scene package. Validate with <verified-cpython-3.14> scripts/validate_ai_video.py scene-prompt <prompt> [--check-paths --project-root <project-root>] [--profile <name>].

Cut structure

Declare whether the scene is one continuous shot or an ordered multi-cut scene. Never apply a global one continuous shot constraint to a multi-cut scene. For each cut, describe preparation, action, result, camera path, and handoff state. Treat storyboard panels as motion samples rather than render style. Keep the story scene intact when a provider limit requires multiple generation jobs; record the job split separately.

AI Video Production knowledge map

Object Sheet

Create one clean reference board for one reusable prop or practical object that can exist independently of a character. Show three complete primary views at matching scale, supplementary compatible angles or states, and construction or material close-ups.

Keep silhouette, dimensions, openings, component positions, finishes, and scale relationships identical across panels. Separate broken, contaminated, transformed, or materially different states. This construction sheet excludes hands, people, scenery, labels, UI, brands, logos, watermarks, and unrelated accessories.

Scene-state reference

Create a separate scene-state reference when a visible screen, page, reflection, control, grip, contact point, open/closed state, damage state, or emitted effect matters. Name it with object ID, scene or cut ID, and state ID. A state reference may show an ordinary readable interface, plausible fictional text, or the operating hand when those details are story content. Keep credentials, real private data, production annotations, and editorial overlays out of it. Use realistic keyboard layouts and home-position contact, sufficient natural paragraph density on paper, and an ordinary application hierarchy on screens.

接続点と見える状態

反復する物体では、人体や環境への接続点、向き、太さ、分岐、見える部分を状態別に明記する。構造の説明用参照と、そのショットで見せる状態の参照を区別し、断面や説明図の表示を意図せず映像へ持ち込まない。

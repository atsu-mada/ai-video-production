Shared Validation and Stop Conditions

Production Package Validation

Validate the smallest relevant artifact first, then validate the package that joins the artifacts.

  • Every path in a manifest stays inside the project root. New manifest paths resolve from the project root; legacy paths beginning with ../ resolve from 99_manifests/ only through the validator's bounded compatibility rule. Cut prompts, scene prompts, and generation handoffs declare local references with Markdown links; raw path-like entries are invalid when path checking is enabled.
  • IDs are stable, unique within their manifest, and use the declared prefix or project convention.
  • Start and end times are ordered; duration equals end - start; overlapping cuts are deliberate and documented.
  • Every scene has an overview, common-asset list, image storyboard, text storyboard, cut prompts, and scene manifest when those deliverables are part of the package.
  • Character, environment, object, and VFX references describe one stable subject or effect family and do not silently mix incompatible states.
  • Environment coverage accounts for every camera start, travel path, endpoint, entrance, exit, reverse, and reflection used by the approved cuts.
  • Every major interactive or close-up object has one construction reference and a dedicated state reference wherever its screen, page, reflection, orientation, contact, opening, damage, or emitted effect changes.
  • A scene, cut, motion beat, and provider generation job use separate IDs and mappings. Provider limits do not silently renumber story scenes.
  • Image-only storyboards reject readable production text and arrows inside picture panels. Text storyboards retain panel order and contain exactly the required fields.
  • Prompt and handoff validation does not submit a generation job. Stop if fixing a validation error would require moving, overwriting, or deleting user files.
  • Recurring assets are not silently duplicated as scene-specific variants.
  • Existing drafts and unrelated files remain untouched.

Run validation

Run <verified-cpython-3.14> scripts/validate_production_package.py <project-root>. Stop if a target exists with conflicting content or if fixing validation would require moving or deleting user files.

Run <verified-cpython-3.14> scripts/validate_ai_video.py <mode> <path> for the selected artifact. For cut prompts, scene prompts, and generation handoffs, use --check-paths --project-root <project-root> when references must be resolved from a prompt file; the explicit root is the containment boundary. A successful path check requires at least one parsed in-root local Markdown link; explicit HTTP or HTTPS links remain external references.

状態と証拠を分離する

確認対象十分な証拠そこから推定しないこと
プロバイダーの状態受理・キュー・生成中・完了・失敗の実表示映像の品質合格や保存済み
技術QC実ファイル、ハッシュ、尺、映像・音声ストリーム演技、連続性、口形同期の合格
知覚レビュー対象区間を再生して観測した判断と根拠人による採用承認
採用・編集承認参照と版を固定した選択リスト保存・書き出し・公開済み
保存・書き出し・公開それぞれの操作結果と対象の再確認他の工程も完了したこと

未確認は未確認のまま残す。技術情報が正しく、元音声と出力音声が一致していても、口形の同期が未視聴なら合格にしない。編集用の記録検査と、人の観測・承認は別である。
